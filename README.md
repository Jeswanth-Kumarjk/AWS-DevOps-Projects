# AWS DevOps Projects

This repository contains hands-on AWS DevOps projects focused on infrastructure automation, CI/CD, and cloud deployment.

## Projects

### 1. AWS Infrastructure Automation using Terraform
- Provisioned AWS infrastructure using Terraform (Infrastructure as Code).
- Automated AWS resource configuration and deployment.
- Used Terraform variables for reusable infrastructure configuration.
- Managed Terraform configuration using Git and GitHub.

### 2. CI/CD Pipeline for Java Web Application Deployment
- Containerized a Java web application using Docker.
- Built an end-to-end CI/CD pipeline using GitHub Actions.
- Automated application build, test, and deployment workflows.
- Deployed the containerized application to AWS EC2.
